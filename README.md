## HR Analytics Dashboard

## Project Overview

Developed an interactive HR Analytics Dashboard using Microsoft Power BI
to analyze employee attrition, workforce demographics, salary levels,
job roles, departments, and job satisfaction.

The dashboard provides a consolidated view of key HR metrics and helps
identify patterns and factors associated with employee attrition.

## Tools Used

- Power BI
- Data Cleaning
- Data Visualization
- DAX

## Key KPIs

| KPI | Value |
|---|---:|
| Total Employees | 1.47K |
| Active Employees | 1.23K |
| Attrition Count | 237 |
| Attrition Rate | 16.1% |
| Average Age | 36.92 |
| Average Experience | 7.01 Years |

## Dashboard Analysis

The dashboard analyzes:

- Department-wise employee count
- Employee attrition by department
- Attrition by salary slab
- Attrition by gender
- Attrition by job role
- Job satisfaction levels
- Workforce demographics
- Employee experience

## Key Insights

- The dashboard recorded 237 employee attritions.
- The overall attrition rate was 16.1%.
- Sales had the highest employee count among the analyzed departments.
- Attrition varies across different salary slabs and job roles.
- Employee attrition was analyzed by gender to identify workforce patterns.
- Job satisfaction was compared across different job roles.
